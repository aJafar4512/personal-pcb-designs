# personal-pcb-designs
PCB designs including schematics, layouts and manufacturing files primarily using Altium designer. I have created these in my own time and this repository aims to showcase my skills and experience. Some designs are proof of concepts rather than intended final products; they are still designed according to manufacturer and assembler capabilities, but may have certain components which need to be reselected and the BoMs may need more work. I have included details of each project, considerations when designing and problems with the final design.
